02Flagship · open source
ReclaimNet

Confidence-scored liveness for IP address space.

Your IPAM says an address is in use. The wire says nothing's there. ReclaimNet reconciles the two — gathering evidence from independent collectors over time and scoring how alive each address really is.

It never declares an IP dead on a hunch. It watches, accumulates proof, and only commits when it's certain.

  • Evidence over guesses — every verdict carries its proof trail.
  • Confidence, not booleans — a score and a trust level, never a blind "dead."
  • Modular collectors — ARP, ping, cloud, DHCP; add a source, the core never changes.
  • Never auto-reclaims — the call stays with a human, with eyes open.
